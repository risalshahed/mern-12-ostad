# Blog & Comment Join API

## Clone the Repository

```bash
git clone https://github.com/risalshahed/mern-12-ostad.git
```

## Change the Directory

```bash
cd mern-12-ostad
```

## Switch to the Branch

### Either with

```bash
git switch module-19-blog-comment
```

### OR

```bash
git checkout module-19-blog-comment
```

## Install & Run the Project

```bash
npm i
npm run dev
```
